# Pierza Studio

Premium Body Piercing & Fine Jewelry Studio website.

## Folder Structure
- `index.html`: Home page
- `pages/`: Internal pages (Portfolio, Shop, Dashboard, etc.)
- `css/`: Modular stylesheets (Variables, Global, Components, Home, Dashboard)
- `js/`: Modular scripts (Main, Navbar, Booking, Dashboard)
- `assets/`: Static assets (Images, Icons)

## Technology Stack
- HTML5
- CSS3 (Vanilla)
- JavaScript (Vanilla)
- Lucide Icons
- Google Fonts (Playfair Display & Inter)
